# スクリーンショットで見て直す

コードを読んでいるだけでは、余白の詰まり・折り返しの崩れ・重なりは見つからない。**作ったら必ず描画して、画像を見て直す。** このスキルで実際に見つかった崩れの例：スマホで表の数字が 1 桁ずつ折り返す、FAB が金額を隠す、色の混合で枠が紫になる、カード内に大きな空白ができる。どれもコード上は正しく見えていた。

## 撮り方

`scripts/capture.mjs`（Node.js 22 以上。npm パッケージ不要。Chrome / Edge / Chromium を使う）：

```bash
# デスクトップ（1440px）とスマホ（390px）の 1 画面目
node scripts/capture.mjs path/to/page.html

# ページ全体・ダークモードも
node scripts/capture.mjs path/to/page.html --full --theme both

# 開発サーバーのページ
node scripts/capture.mjs http://localhost:5173/settings --viewports desktop,mobile

# お手本をアクセント色違いで
node scripts/capture.mjs assets/exemplars/landing.html --query accent=teal
```

- 画像は `.ux-shots/`（`--out-dir` で変更可）に保存される。Read ツールなどで画像を開いて見る
- スマホは 390×844・2 倍解像度・タッチ端末として模擬する（`pointer: coarse` の指定も効く）
- `--full` は縦 8000px までで止める。縦に長いページは、1 画面目と気になる部分を別々に確認する
- `position: fixed` や下端に `sticky` した要素（保存バー、チャットの入力欄など）は、全体撮影では最初の画面の位置（途中）に写る。実際の画面ではスクロールしても画面下端に表示される。重なり方は `--full` なしの 1 画面目で確かめる
- ブラウザが見つからない場合は `--browser <パス>` か環境変数 `UX_BROWSER` で指定する

## 見る順番

1 枚ごとに上から順に確認し、見つけたものはその場で直して撮り直す。

### 1. 3 秒で分かるか

- [ ] 何の画面か、見出しを読まずに分かる
- [ ] 次に押すべきボタンが 1 つに決まる
- [ ] 目を細めたとき、いちばん目立つのが最重要の要素になっている

### 2. 整列と余白

- [ ] 左端がそろっている線の数が少ない（バラバラに始まる要素がない）
- [ ] グループ内は詰まり、グループ間は空いている（均一な余白になっていない）
- [ ] 見出しが上の塊ではなく下の内容にくっついている
- [ ] カードの中に意図しない大きな空白がない（並んだカードの高さに引っ張られていないか）

### 3. 文字

- [ ] 文字サイズの段数が 4〜5 段以内
- [ ] 日本語の見出しやボタンが、1〜2 文字だけ次の行に落ちていない
- [ ] 数字や ID が途中で折り返していない
- [ ] 本文の 1 行が長すぎない（40 字前後）

### 4. 色

- [ ] アクセント色の面積が画面の 1 割以下で、意味のある場所だけに使われている
- [ ] 状態が色だけでなく文言やアイコンでも分かる
- [ ] 意図しない色（混ぜた色・透けた色）が出ていない
- [ ] ダークモードでも境界と重なりが見える

### 5. スマホ

- [ ] 横スクロールが発生していない
- [ ] 固定要素（タブバー・FAB・保存バー）が大事な情報を隠していない
- [ ] タップする部品が小さすぎない（44px 以上）
- [ ] 表はカード型の行になっている

### 6. 状態と中身

- [ ] 空・読み込み中・エラーの画面がある
- [ ] 長い名前、0 件、桁の多い数値で崩れない（実データに近い長さで見る）

## 機械検査と組み合わせる

画像で見るのは「見た目の判断」。数値で判定できる項目は機械に任せる：

```bash
python scripts/ux_audit.py audit --path <実装ディレクトリ> --fail-on error
python scripts/ux_audit.py tokens --file <tokens.css>
```

`audit` が PASS でも見た目が良いとは限らない。逆に、スクリーンショットで良く見えても、コントラストやフォーカスの不備は画像では分からない。両方やる。
