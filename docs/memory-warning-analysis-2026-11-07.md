# メモリが緑でも警告文と黄色いアイコンが出る問題

更新日: 2026-11-07

## 現象と変更履歴

物理メモリ使用率 47.5%、空き 25.1 GB、ページファイル増加なしの画面で「メモリが少なくなっています」という黄色い文が表示され、システムモニタのアイコンも注意色になっていた。

| 変更 | コミット | 内容 |
|---|---|---|
| 2026-10-27 | `dea901b` | ページファイル表示と警告文を追加 |
| 2026-10-31 | `d2df22c` | ページファイルの警告をタイトルバーのアイコン色へ反映 |
| 2026-11-07 | `652d8b2` | CacheStorage 回収を追加。メモリ警告の判定・表示・アイコン色は変更していない |

## 原因

バーは物理メモリの使用率、警告文はコミット率を使っていた。これらは別の指標なので、緑のバーと黄色い警告が同時に表示される。画像の警告文は従来のコミット率75%以上90%未満の分岐と一致するが、画像にコミットの実測値は表示されていない。
また、ページファイルが一度256 MB以上拡張すると、物理メモリの空きが回復しても「拡張あり」を警告として優先し続けていた。ページファイル無効時も使用量にかかわらず注意としていた。

物理メモリとコミットの各値の意味は [Microsoft の MEMORYSTATUSEX 定義](https://learn.microsoft.com/windows/win32/api/sysinfoapi/ns-sysinfoapi-memorystatusex) を参照。

## 修正

- メモリカードの警告文とページファイル由来のアイコン色を、表示中の物理メモリ使用率に統一。75%未満は正常、75%以上は注意、90%以上は警告とする。
- 正常時の警告文は空にして非表示にする。過去のページファイル増加、無効設定、コミット率だけでは警告色を残さない。
- モニタを開いている間も閉じている間も、その回のメモリ計測値を同じ判定処理へ渡す。
- ページファイル容量・増加量は従来どおり通常色で表示し、コミット情報はツールチップで確認できる。拡張時期や再起動での縮小を断定する文言を改めた。
- CPU・ディスクの警告基準と集約は維持する。それらが注意/警告であれば、メモリが緑でもアイコンは注意/警告色になる。

この表示方針では、コミットの上限が近いという理由だけでは警告を出さない。コミット上限の詳細を調べる場合はページファイル行のツールチップを使う。

## 検証

`MemoryWarningTests` で画像相当の47.5%、高いコミット率、ページファイル拡張履歴、無効/不明設定、75%/90%の境界、高負荷からの回復、CPU警告の保持を確認する。既存のページファイル・タイトルバー集約テストも新しい表示方針に合わせた。

ソリューションビルドは警告・エラー0。追加12件を含む回帰チェック218件が合格。実行中アプリの差し替えや実画面での確認は未実施。
