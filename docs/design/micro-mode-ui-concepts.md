# 極小表示（Micro モード）UI/UX 設計検討・代替案メモ

[ドキュメント一覧へ戻る](../index.md)

作成日: 2026-11-26。本資料は、4 分割画面の中央に配置する極小表示（Micro モード）の視認性・操作性改善にあたり検討した 3 つの設計案（案 A / 案 B / 案 C）の比較と、**採用した案 B（円形オービット・ダイヤル）の仕様**、および**将来的に切り替え・再検討できるよう保存しておく案 C（超極小宝石 → ミニダッシュボード変形）の設計メモ**を記録したものです。

---

## 1. 背景と改善対象（旧 116×116 四角 UI の課題）

4 分割したワークスペースの中央交差点に配置する前提（AI 操作は右端ペイン中心のため中央配置が邪魔になりにくい）において、従来の 116×116 四角形 UI には以下の課題がありました。

1. **先頭 2 文字ラベルの識別限界**: プロジェクト名に `AI-...` のような共通接頭辞があると `AI` / `AI` / `ター` / `Ge` のように重複し、スロット判別が困難。
2. **上部 4 アイコンの圧迫と誤操作**: 116px 幅の上辺に `⤢` `⤡` `－` `×` が密集し、面積の約 3 割を占有。
3. **不透明な角の干渉**: 四角い角が背後 VS Code のサイドバーアイコン（歯車・アクティビティバー等）に被る。
4. **他モード操作への到達性不足**: 「控え一覧の閲覧・入替」「最前面／最背面」「補助 AI アプリ」へ極小表示から直接アクセスできない。

---

## 2. 検討した 3 案の比較

| 項目 | 案 A: スマート・ミニ四角 | 案 B: 円形オービット・ダイヤル（**採用**） | 案 C: 超極小宝石 → ミニダッシュボード変形（**保留・再利用候補**） |
|---|---|---|---|
| **平常時のサイズ** | 約 `186 × 106 DIP`（横長四角） | 直径 `116 DIP`（真円コア、角なし） | 直径 `56 DIP`（超極小丸玉・光る 4 ドット） |
| **平常時の視界占有** | 中 | 小（角がなく、透過ゴーストで背景に溶ける） | 最小（従来比 約 1/4） |
| **タイトル視認性** | 短い識別名（5〜6 文字）を常時表示 | 4 扇に `A〜D`＋アプリ色ドット＋識別短縮名、ホバー／ホイールで **0ms ライブ情報ピル**（フルタイトル＋AI 状態） | ホバー展開時に縮小表示並みのフル寄りタイトルを 4 件一括表示 |
| **1 クリック即操作** | 可能 | 可能（平常時から 4 扇が直接押せる） | 不可（ホバー展開の 1 テンポが必要） |
| **控え一覧・前後操作** | 上部に控えボタンを追加 | ホバー開花する下弧ダイヤルからワンクリック | 展開したミニダッシュボード下段からワンクリック |
| **ダイヤル操作（ホイール）** | なし | **あり**（ホイール回転で A〜D 巡回プレビュー＆クリック切替） | なし |
| **既存 UI への影響** | 低 | 中（専用透過ウィンドウ `MicroDialWindow`） | 中〜高（専用透過ウィンドウ＋展開サイズ変形） |

## 3. 採用案: 案 B「円形オービット・ダイヤル」仕様概要

### 構造と WPF 実現方式
- `MainWindow` は `AllowsTransparency=False`（`WindowChrome` 付き）を維持し、標準・縮小表示の安定性やタスクバー連携をそのまま保つ。
- 極小モード中のみ `MainWindow` を `DWMWA_CLOAK = 1` で視覚・入力透過の待機状態とし、専用の `AllowsTransparency=True` フローティングウィンドウ **`MicroDialWindow`** を表示する（`DWMWA_CLOAK` 失敗時は従来 `MainWindow` の `MicroPanel` へ自動フォールバック）。
- `MicroDialWindow` の背景は完全透明（`Brushes.Transparent`）のため、円形コアの外側や非展開時の外周余白は WPF ヒットテストを素通りし、背後の VS Code をそのままクリック・操作できる。

### 主なインタラクション
1. **普段（ゴースト透過）**: 直径 `116 DIP` の 4 分割クォーター円盤が半透明（既定 `Opacity = 0.48`、右クリックメニュー等で ON/OFF 可）で中央に浮かぶ。AI が作業中または完了しているときは自動で `Opacity = 0.86` へ引き上げて視認性を確保する。
2. **スマート識別ラベル**: 複数スロット間で共通接頭辞（例: `AI-`）が重複する場合は自動スキップして特徴語（`Usage` / `Agent` 等）を抽出し、`A〜D` 記号＋アプリ種別色ドットとともに各扇へ表示する。
3. **ホバー開花（外周ダイヤル）**: マウスが乗ると `Opacity = 1.0` へ実体化し、外周リングに上弧（`標準` `縮小` `最小化` `閉じる`）・下弧（`控え一覧` `前` `背` `AIアプリ`）が滑らかに展開する。
4. **0ms ライブ情報ピル**: 扇へのホバーまたはマウスホイール回転中、遅延ゼロの透過ポップアップでフルタイトル・アプリ種別・AI 経過時間／完了状態を表示する。
5. **控え一覧連携**: 下弧の `控え` ボタンで既存の `StoredOverviewPopup` をダイヤル横へそのまま展開。控えカード選択時は 4 扇が「入替先選択モード」になり、クリックまたはドラッグ＆ドロップで入れ替え可能。
6. **モード切替モーフィング**: `ModeMorphGhostWindow` の角丸を `8 ⇄ 58` へ同時補間し、四角パネルと真円ダイヤルが滑らかに変形遷移する。

## 4. 将来の再検討用メモ: 案 C「超極小宝石 → ミニダッシュボード変形」

> [!NOTE]
> 案 B を実運用してみて「平常時をもっと小さくしたい」「ホバーした瞬間に 4 つすべてのフルタイトルを一覧で見たい」と感じた場合に、同じ `AllowsTransparency=True` 基盤を活かして切り替えられるよう、案 C の設計詳細をここに残します。

### コンセプト
**「普段は 56px の宝石（ステータスインジケーター）、触れた瞬間だけ 236×140px の縮小ミニダッシュボードへ変形」**

### 平常時（折りたたみ状態）
- **形状・寸法**: `56 × 56 DIP` の真円（`CornerRadius = 28`）。
- **中身**: 2×2 に並んだ 4 つの小型ステータスドット（各 `12 × 12 DIP`, 角丸 `3`）。
  - 通常待機: `#3A4A42` / フォーカス中: `#7AE9AB` / AI 作業中: `#45D483`（＋外周円弧を緑 LED が周回） / AI 完了: `#48B2FF`（3.0 秒ホタル点滅）。
- **透過**: 非ホバー時は `Opacity = 0.45`（AI 通知中は `0.72`）。
- **利点**: 4 画面の中央交差点に点のように収まり、どの画面の要素ともほぼ干渉しない。

### ホバー展開時（ミニダッシュボード状態）
- **変形アニメーション**: マウス進入で `240ms`（`CubicEase EaseOut`）かけて `56×56（角丸 28） → 236×140（角丸 14）` へ中心基準で滑らかに変形し、`70ms` 遅れて内部 UI が `180ms` でフェードイン。マウス退出時は少し猶予（例: `180ms` デバウンス）を置いてから `56×56` の宝石へ戻る。
- **展開後のレイアウト（3 段構成）**:
  1. **ヘッダー行**: 左に `Quartet Micro`（ドラッグ移動ハンドル兼用）、右に `前` `背` `⤢（標準）` `⤡（縮小）` `－` `×`。
  2. **2×2 スロットグリッド**: 各セルに「アプリ色ドット＋**フル寄りプロジェクト名（最大 12〜14 文字表示）**＋AI 作業中ドット／完了青点滅」。クリックで 1 面フォーカス／4 面トグル。
  3. **フッター行**: 左に `一括非表示 / すべて再表示`、右に `▤ 控え一覧`（既存の `StoredOverviewPopup` を横へ展開）。

### 案 B から案 C へ切り替える（または設定で選択式にする）際の実装メモ
- 案 B で導入する **`MainWindow` の Cloak 連携・タスクバー最小化／復元連携・`ModeMorphGhostWindow` の角丸補間・`StoredOverviewPopup` の極小表示連携** はそのまま 100% 流用可能。
- 差し替えるのは `MicroDialWindow` のビジュアル（`116px` 4 扇＋外周サテライト → `56px` 宝石＋`236×140` 展開パネル）のみ。
- 案 C 実装時の UX 注意点:
  - マウスが一瞬かすめただけで毎回大きく開くと煩わしいため、**展開開始に `80〜120ms` のホバー意図確認ディレイ**を入れるか、**クリック／ホバー選択式**にするのが望ましい。
  - マウスが外れて即座に閉じると端のボタンを押す途中で畳まれやすいため、**折りたたみ側にも `200ms` 前後の猶予**を持たせ、控え一覧が開いている間は展開をロックする。
- もし将来「設定画面から極小スタイルを『円形ダイヤル（案 B）』／『超極小宝石（案 C）』で選べる」ようにすれば、両方の良さを活かすことも可能です。
