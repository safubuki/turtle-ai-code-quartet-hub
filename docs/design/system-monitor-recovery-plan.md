# システムモニタの折りたたみと VS Code 終了・復旧

[ドキュメント一覧へ](../index.md)

作成日: 2026-11-12

## 仕様

- 各フォルダの使用量は、表のワークスペース・控えのワークスペース・アプリのデータ・AI エージェントのデータと一時フォルダの4分類を個別に展開する。
- モニタを開いた時点は全分類を閉じる。見出し・件数・開く操作を表示し、展開時に説明と既存のフォルダカードを表示する。同じモニタ内の再計測では開閉状態を保つ。
- 既存の非同期計測、キャンセル、フォルダを開く操作、容量解析、ディスク整理を維持する。
- モニタ内に「VS Code の終了・復旧」を追加する。ボタンから現在のユーザー・Windows セッションの Code.exe / Code - Insiders.exe を列挙し、対象と警告を表示する。
- 明示的な「強制終了する」の確定だけで、表示したプロセスを停止する。ハブ外の VS Code も対象であること、未保存の編集喪失とターミナル・AI 処理中断の可能性を明記する。
- Antigravity、他のアプリ、別ユーザー、実行ファイルを確認できないプロセスは停止しない。子プロセスの一括終了を使わない。PID・開始時刻・実行パス・所有者・セッションを再確認する。
- 実行後は終了済み・失敗・残留を表示する。後から起動した未確認プロセスは追加で終了せず、再確認を案内する。再起動はユーザーに任せる。

- [x] Phase 2（Phase 1と並行可能）: VS Code 対象検出・終了サービスと安全性テストを実装。

検証では実ユーザーの VS Code を終了しない。プロセス停止の検証は注入した代替実装を使用する。

## 検証結果

- 本体ビルドは警告・エラー0。回帰テスト259件に合格（終了・復旧の安全性14件を含む）。
- 非表示WPF描画で650 / 580 DIP幅の全閉・開閉・再計測相当の一覧再生成・確認取消・長い対象一覧と取得失敗メッセージを確認した。
- 非表示中のVS Code終了後を合成状態で再現し、全窓が消えたときのスロット・非表示履歴・標準/縮小/極小の表示ボタンの復帰を確認した。
